WINDOWS & LINUX · BETA

কম্পিউটারেও নিজের পড়ার জায়গা

অন্তর্ভুক্ত পেজ, স্থানীয় বাংলা ফন্ট, ১৩০ প্রশ্নের বাংলা MCQ ও ট্র্যাকার অফলাইনে ব্যবহার করো। প্রতিটি অপারেটিং সিস্টেমের জন্য আলাদা প্যাকেজ।

⬇ Windows x64 installer ⬇ Linux x64 AppImage

Windows 10/11 x64: .exe installer চালিয়ে নিজের account-এ ইনস্টল করো। Chromium সঙ্গে আছে; আলাদা .NET বা WebView2 Runtime লাগে না। এটি unsigned beta, তাই SmartScreen সতর্ক করতে পারে। সুরক্ষা ব্যবস্থা বন্ধ না করে সতর্কতা পড়ে সিদ্ধান্ত নাও।

Linux x86_64: AppImage ফাইলে execute permission দিয়ে চালাও: chmod +x ফাইলের-নাম.AppImage। কিছু distribution-এ FUSE এবং উপযুক্ত system library লাগতে পারে। FUSE না থাকলে release-এর extraction নির্দেশনা দেখো। root হিসেবে চালাবে না বা sandbox বন্ধ করবে না।

এই প্যাকেজগুলো ARM Windows/Linux-এর native build নয়। Desktop-এ নতুন সাইটের তথ্য পেতে নতুন অ্যাপ সংস্করণ লাগবে; কোনো binary auto-update নেই। ভিডিও, feedback, বাইরের portal ও WhatsApp-এ ইন্টারনেট লাগবে।

Android-এ শুরু করো

কীভাবে ইনস্টল করবে?

  1. ১
    APK ডাউনলোড করো

    উপরের বোতাম এই সাইটের নিজস্ব GitHub release থেকে APK নামায়। চাইলে আগে প্রকাশিত SHA-256 checksum মিলিয়ে নাও।

  2. ২
    ডাউনলোড করা ফাইল খোলো

    ফোনের Downloads থেকে ফাইলটি খুলে ইনস্টল চাপো। Android System WebView হালনাগাদ রাখো।

  3. ৩
    প্রয়োজনীয় অনুমতি সীমিত রাখো

    Android চাইলে শুধু ব্যবহৃত browser/file manager-এর জন্য “Install unknown apps” অনুমতি দাও। সতর্কতা পড়ে সিদ্ধান্ত নাও এবং ইনস্টলের পর অনুমতি বন্ধ করো।

জরুরি তথ্য

এটি পরীক্ষামূলক সংস্করণ

Android প্যাকেজটি debug-signed ও debuggable APK, Play Store সংস্করণ নয়। স্থায়ী signing key এখনো সেট করা নেই; ভবিষ্যৎ build সরাসরি update নাও হতে পারে। Windows প্যাকেজ unsigned।

নতুন অ্যাপের পরিচয় আলাদা; পুরোনো HSC 2027 অ্যাপের পাশাপাশি রাখা যায়। অ্যাপ, পুরোনো অ্যাপ ও ব্রাউজারের অগ্রগতি আলাদা—স্বয়ংক্রিয় স্থানান্তর বা sync হয় না। পুরোনো তথ্য রাখতে পুরোনো অ্যাপ আনইনস্টল কোরো না। আনইনস্টল করলে অ্যাপের স্থানীয় ট্র্যাকার তথ্য মুছে যাবে।

Android অনলাইনে সম্পূর্ণ hash-যাচাইকৃত site update প্রস্তুত করতে পারে, তোমার সম্মতির পর চালু হয়। MCQ উত্তর/নম্বর সার্ভারে যায় না; পেজ refresh করলে চলমান টেস্ট মুছে যায়। কোনো portal password এই অ্যাপে নেওয়া হয় না।
