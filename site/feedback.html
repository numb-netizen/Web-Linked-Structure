তোমার মতামত জানাও

কোনো ভুল, সাইট ব্যবহারের সমস্যা অথবা নতুন ধারণা? নিচে লিখে জানাও। তোমার পরামর্শ আমাদের সাইটকে আরও ভালো করতে সাহায্য করবে।

প্রকাশ্য তথ্য: তোমার লেখা GitHub Issue হিসেবে সবাই দেখতে পারবে। ফোন নম্বর, রোল নম্বর, পাসওয়ার্ড বা ব্যক্তিগত তথ্য লিখো না। নিরাপত্তার দুর্বলতা নিচের গোপন রিপোর্টের পথে জানাও।

সর্বোচ্চ ৫০০ অক্ষর। সংবেদনশীল বা ব্যক্তিগত তথ্য দিও না।

GitHub অ্যাকাউন্ট লাগে না। পাঠানোর পর মতামত গ্রহণ করা হলে তা কিছু সময় পরে প্রকাশ্য Issue হিসেবে যুক্ত হবে; ইন্টারনেট প্রয়োজন। স্প্যাম ঠেকাতে পাঠানোর সংখ্যা সীমিত।
